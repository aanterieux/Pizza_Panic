# Controls

## Menu
| Action | Keyboard / Mouse | Controller |
|---|---|---|
| Navigate menu | Mouse Hover | Left Stick Up/Down / Up/Down D-Pad |
| Press button | Left Click | Bottom Face Button |

## Game
| Action | Keyboard / Mouse | Controller |
|---|---|---|
| Move | W / A / S / D | Left Stick (Move) |
| Look Around | Mouse Movement | Right Stick (Move) |
| Toggle Run | Left Shift | Left Stick (Press) |
| Jump | Space | Bottom Face Button |
| Pickup Item | Right Click | Left Trigger |
| Drop Item | Right Click | Left Trigger |
| Throw Item | Left Click | Right Trigger |
| Shoot | Left Click | Right Trigger |
| Reload | R | Left Face Button |
